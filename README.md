# Autunn

我做车机应用、网络管理工具和家庭自动化。项目从原生桌面应用、Go 服务，一直到浏览器里的 3D 仪表盘。

## 代表作品

### [UniFi Policy Manager](https://github.com/autunn/unifi-policy-manager)

基于 UniFi 官方 Integration API 的 Windows / macOS 原生桌面工具。可对比 DNS、ACL 和防火墙策略基线，在应用变更前预览差异并保存快照。

### [NasNotify-Go](https://github.com/autunn/nasnotify_go)

用 Go + Vite 构建的绿联 NAS 通知与控制中心。支持企业微信和微信 ClawBot，常用查询可渲染为 PNG 状态卡片，并支持 Docker、macOS DMG 和绿联 UPK 打包。

### [Home Assistant Digital Twin](https://github.com/autunn/home-assistant-digital-twin)

把 Three.js 3D 场景接进 Home Assistant 仪表盘。仓库包含 Docker Compose 部署基线、YAML 仪表盘和 GLB 场景资产。

### [Autunn Play](https://autunn.github.io/)

面向红旗 HS5 的 CarPlay 适配项目。官网展示中控实机界面和车型适配信息。
